# EthDenver

Chisel experiments and planning for connecting ETHDenver visitors with Denver's existing communities.

## Proposed 2027 outside event

A soft-tip electronic dartboard at a Denver bar reports signed game events through Chisel. A receiver and viewer on the hacker floor let convention participants and bar regulars see the same game and its persistent record.

John plans to spend up to one week in Denver and move between the hacker floor and the bar to involve participants. Nob Hill Inn is the proposed bar, subject to arranging the event with its operator. This is an independently organized outside-event proposal. Dates, venue participation, and any convention-floor setup remain to be confirmed.

- [Dartboard pilot: event, device identity, radio transport, and implementation plan](docs/nob-hill-dartboard-pilot.md)
- [Invitation for Albuquerque colleges, hackerspaces, and makerspaces](docs/college-makerspace-invitation.md)

The existing application files preserve earlier Web3, QR, and ledger experiments. The new documents describe a proposed build; they do not implement the hardware or change the existing application.

Use this repository's issues to coordinate the pilot.
